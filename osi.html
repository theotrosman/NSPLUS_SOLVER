Modelo OSI y TCP/IP, capa por capa.

Qué hace cada capa, cómo se llaman los datos (PDU), qué protocolos y dispositivos trabajan ahí, y cómo se corresponden OSI y TCP/IP. Abajo, una práctica para estudiar.

Tocá una capa para ver el detalle. Para acordarte de OSI de abajo hacia arriba: Física, Enlace, Red, Transporte, Sesión, Presentación, Aplicación.

Cuando mandás algo (por ejemplo, abrir una página web), los datos bajan por las capas y cada una les agrega su propia "etiqueta" (encabezado). Del otro lado suben y cada capa saca la suya.
